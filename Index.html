conectado a Drive
Gestiona y sube documentos directamente a Google Drive desde esta app. Solo necesitas un API Key y un Client ID gratuitos de Google Cloud.
1
Crea un proyecto en Google Cloud
Ve a console.cloud.google.com → "Nuevo proyecto". Es gratis.
2
Activa Google Drive API y Google Picker API
En "APIs y servicios" → "Biblioteca" → busca y activa ambas APIs.
3
Crea credenciales
"Credenciales" → crea un API Key y un OAuth 2.0 Client ID (tipo: Web application). Agrega tu dominio en "Authorized JavaScript origins".
